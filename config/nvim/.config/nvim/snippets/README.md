# Key snippets included:

## Templates:

- cptemplate - Basic template
- cpt - Template with testcases (for Codeforces Div 2/3)
- cpdebug - Template with debug macros
- cpgraph - Graph problems template
- cpdp - DP problems template

## Algorithms:

- bfs - BFS traversal
- dijkstra - Dijkstra's algorithm
- binsearch - Binary search
- segtree - Segment tree (for CSES range queries)
- dsu - Union-Find (for connectivity problems)

## Data Structures:

- vec, vec2d - Vectors
- map, set - STL containers
- pqmax, pqmin - Priority queues

## Utilities:

- reada, printa - Read/print arrays
- mod - Modular arithmetic (for large number problems)
- fori, forr, fore - Different loop types

Most CSES problems use cptemplate, while Codeforces usually needs cpt (multiple testcases).
Just type the prefix and hit Tab!

# Added LeetCode templates! Here are the new snippets:

## Basic Templates:

- lcsol - Generic solution class
- lcarr - Array problem

## Algorithm Templates:

- lcdp - 1D DP problem
- lcdp2d - 2D DP problem
- lcback - Backtracking (permutations, combinations, subsets)
- lcslide - Sliding window
- lcbs - Binary search
- lc2ptr - Two pointers
- lctrie - Trie data structure

## Testing:

- lcmain - Main function for local testing (paste LeetCode solution and test locally)

## Usage example:

Start a new file for a LeetCode problem
Type lctree + Tab for a tree problem
Fill in the function name and logic
Copy to LeetCode or use lcmain to test locally

These templates include the exact LeetCode comment blocks for TreeNode and ListNode definitions!
